which is licensed the same way.


## Do I need a commercial license?

| Your use | License |
|---|---|
| Research, teaching, study, personal projects | AGPL v3 — free |
| An open-source project released under the AGPL v3 (or the GPL v3, which can be combined with it) | AGPL v3 — free |
| Internal use in an organisation, with no copies given to others and no access over a network for people outside it | AGPL v3 — free |
| A product or service you distribute or offer over a network, with its complete source code published under the AGPL v3 | AGPL v3 — free |
| A closed-source product that includes a sequentialist library (application, library, device, firmware) | **commercial license** |
| A network service (SaaS, API, web application, an experimentation platform) built with a sequentialist library whose source code you do not publish | **commercial license** |
| Your organisation's policy does not allow AGPL software, or you need warranty, support or indemnification | **commercial license** |

Every sequentialist library depends on sequential-analysis. A commercial
license for a sequentialist library therefore covers sequential-analysis as
used by it; both are licensed by the same company.

# Лицензирование

Библиотеки sequentialist распространяются по двойной лицензии: как открытое
ПО по GNU AGPL v3 и по коммерческой лицензии для продуктов с закрытым
исходным кодом. Они построены на
[sequential-analysis](https://github.com/andre-a-no/sequential-analysis),
которая лицензируется так же.


## Нужна ли вам коммерческая лицензия?

| Как вы используете | Лицензия |
|---|---|
| Исследования, преподавание, обучение, личные проекты | AGPL v3 — бесплатно |
| Открытый проект под AGPL v3 (или GPL v3, совместимой с ней) | AGPL v3 — бесплатно |
| Внутреннее использование в организации без передачи копий и без сетевого доступа для посторонних | AGPL v3 — бесплатно |
| Продукт или сервис, который вы распространяете или предоставляете по сети, с полным исходным кодом, открытым по AGPL v3 | AGPL v3 — бесплатно |
| Закрытый продукт, включающий библиотеку sequentialist (приложение, библиотека, устройство, прошивка) | **коммерческая лицензия** |
| Сетевой сервис (SaaS, API, веб-приложение, платформа экспериментов) на основе библиотеки sequentialist, исходный код которого вы не публикуете | **коммерческая лицензия** |
| Политика вашей организации не допускает ПО под AGPL, или вам нужны гарантии, поддержка, защита от претензий | **коммерческая лицензия** |

Каждая библиотека sequentialist зависит от sequential-analysis.
Коммерческая лицензия на библиотеку sequentialist поэтому покрывает и
sequential-analysis в том объёме, в каком библиотека её использует;
правообладатель у обеих один.
